Stacks

The grind never stops # Stacks

  • Stacks are a restricted access data structure
  • Collections (lists, sets, etc.) are “unstructured”: they just hold stuff
  • You can impose a structure on (say) lists by sorting them: you rearrange the list so that they are “in order”; that’s imposed on the data structure’s state
  • Alternative: create structure through an object/data structure’s behavior: its publicly available interface (public methods)
  • A stack does this by restricting how you interface with it:
  • Basic operations:
    • push: adding an element to the top of the stack
    • pop: removing (and returning) the element at the top of the stack
  • Stacks are LIFO (Last In First Out) data structure
  • This is ensured behavior through the public interface
  • YOU are generally

Stacks Class

private List<T> elements = new ArrayList<>;

/**
 * Adds the given {@code element} to the "top" of the stack
 * @param element
 */
public void push(T element) {
    if(element == null) {
        throw new IllegalArgumentException("You cannot push null values onto this stack");
    }
    //adding an alement to the "end":
    this.elements.add(element);
}

/**
 * Removes and returns the element at the top of this stack
 */
public T pop() {
    if(this.isEmpty()) {
        //option 1: returna a flag value:
        return null;
        // option 2: throw an exception
        throw new IllegalState Exception("You annot pop from an empty stack!");
    }
    return this.elements.remove(this.elements.size()-1);
}

public boolean isEmpty() {
    return (this.elements.isEmpty());
}

Demo

Stack<Integer> s = new Stack<>();

s.push(42);
s.push(35);
s.push(18);

System.out.println(s.pop()); //expected: 18
System.out.println(s.pop()); //expected: 35
System.out.println(s.pop()); //expected: 42
System.out.println(s.pop()); //expected: ??

Queue

  • Is a “line”, a FIFO = First In First out data structure
  • No line jumping! No cutting in line
  • A restricted access data structure
    • enqueue: insert something at the “end” of the queue
    • dequeue: remove and return the element at the “front” of the line
  • Same exact considerations and options as before

Queue Class

private List<T> elements = new LinkedList<>();

public void enqueue(T element) {
    if(element === null) {
        throw new IllegalArgumentException("You cannot enqueue null values");
    }
    this.elements.add(element);
}

public T dequeue() {
    if(this.isEmpty()) {
        throw new IllegalStateException("You cannot dequeue an empty queue!");
    }
}

public boolean isEmpty() {
    return this.elements.isEmpty();
}

Demo

Queue<Integer> q = new LinkedList<>();

q.enqueue(42);
q.enqueue(35);
q.enqueue(18);

System.out.println(q.dequeue()); //expected: 42
System.out.println(q.dequeue()); //expected: 35
System.out.println(q.dequeue()); //expected: 18
System.out.println(q.dequeue()); //expected: ??
